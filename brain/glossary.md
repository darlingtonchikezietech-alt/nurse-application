# Glossary

| Term | Meaning |
|---|---|
| NMCN | Nursing and Midwifery Council of Nigeria, the regulator that registers and licenses nurses and midwives. |
| Licence / card | The practising licence (ID card) a nurse must hold; renewed every 3 years. |
| PUF | Professional Update Form, the online profile on the NMCN portal. Needed before online renewal. |
| RRR | Remita Retrieval Reference, the payment reference for paying NMCN via Remita. |
| Default / penalty | Years a licence has been expired; each year adds a penalty fee. |
| MCPDP / CPD | Mandatory Continuing Professional Development credits. |
| WCEA | Online CPD platform used for NMCN credits, required for diaspora renewals. |
| RN / RM / RPHN / RPN | Registered Nurse / Midwife / Public Health Nurse / Psychiatric Nurse. |
| Client | The nurse paying us for the service. |
| Operator | The person on our team supervising an agent and approving logins and payments. |
| Card Desk | Our dashboard: one record per nurse request. |
